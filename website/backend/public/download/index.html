Child setup

Provision the child's phone

Full app blocking and removal protection require T53 to be the phone's device owner. This setup normally applies only to a new or factory-reset phone without accounts.

QR setup

  1. Start from a new or factory-reset phone; do not add an account first.
  2. At the Android Welcome screen, tap the same spot six times.
  3. Connect to Wi-Fi and scan the QR code shown here.
  4. Wait for Android to finish installing and provisioning T53.

The provisioning QR appears after the signed child APK is published.

Use a computer (advanced)
  1. Install the child APK on a fresh test phone.
  2. Enable Developer options and USB debugging.
  3. Run the device-owner command shown in the T53 child setup screen.

Do not run device-owner provisioning on a phone with important data; it may require a factory reset.

Before you begin

Important notes

  1. Install the Parent app on the parent's phone, or use the web dashboard.
  2. Install/provision T53 Child only on a device you own or are authorized to manage.
  3. Activate the child device using its T53 license code.
  4. Review the app restrictions after the child phone syncs.

T53 cannot bypass Android security controls on an unmanaged device. Do not advertise the child app as fully protected until provisioning and on-device tests succeed.
